# 🛒 Online Store

A simple online store website with product cards and an interactive filter panel.

## ✨ Features

- Product catalog
- Product categories
- Search by product name
- Filter by price
- Sort products by price:
  - Low to high
  - High to low
- Burger button for opening the filter panel
- Dropdown list for product categories
- Clean and simple interface

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript

## 📁 Project structure

```text
project/
├── index.html
├── style.css
├── script.js
├── images/
└── Redmi.md
```

## 🚀 How to run

1. Download or clone the repository.
2. Open the project in **Visual Studio Code**.
3. Open `index.html`.
4. Use **Live Server** or open the HTML file directly in your browser.

## 🔎 Filters

The filter menu contains:

- **Category** — select a product category.
- **Product name** — search for a product by name.
- **Price** — filter products by price.
- **Sort ascending** — products from the cheapest to the most expensive.
- **Sort descending** — products from the most expensive to the cheapest.

## 📱 Responsive design

The project is designed to work on desktop and mobile devices. The filter panel can be opened using the burger button.
